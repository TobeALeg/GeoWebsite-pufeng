# Product

## production

- 用户是谁：寻找针织服装、小批量 OEM 和企业工装供应能力的采购方。
- 核心价值：用真实产品、产能、资质和供应链素材支持采购判断与联系转化。
- 产品原则：事实可核验、素材真实、静态页面快速、SEO/GEO 信息完整。
- 不做什么：不承担 GEO 内容生产，不从 `core.json` 自动重建，不引入 v2 建站逻辑。
- 用户体验路径：首页理解企业与能力 → 查看产品 → 核对资质与 FAQ → 联系工厂。
- 核心衡量：首页或来源渠道访问 → 查看产品与能力 → 产生电话、邮箱或联系区咨询意向。

## ux

- 保持当前生产站的信息架构和视觉，不在迁移中重设计。
- 组件、内容和素材只服务濮丰，后续可以独立演进。
- 埋点用于衡量内容与咨询意向，不把按钮点击表述为真实询价或成交。
